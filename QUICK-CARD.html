MARK A SIGHTING — 3 TAPS

  • Press MARK → say the waypoint # aloud (it shows big — audio cross-ref)
  • Tap the species button
  • Tap the total → SAVE
  • Classes called too? Tap Bulls / Cows / etc. — Total auto-fills
  • Chips: CIRCLED · PHOTOS · CAPTIVE · COLLARED / CHECK · DUP? · NOT DUP + free notes
  • Fix or delete later: tap the pin on the map

COUNTS — THE TOTAL RULE

  • Total alone is fine — type it, SAVE, done
  • Total typed by hand is authoritative — classes never change it
  • Classes only → Total tracks their sum (1 cow + 1 calf = Total 2)
  • Unk = Total − classes — always derived, never typed
  • Classes add up to more than Total → SAVE is blocked until it adds up
  • Strip order: Bulls · Yearlings · Cows · Calves · Unk · Total
  • Templates stack: 1B · 2B · 1C · C+C · C+2C · C+Y

LEGS & CREW — DATA SCREEN

  • HUD shows LEG n · ON while surveying
  • New crew, area, or conditions → STOP LEG, add a leg, fill in crew + weather
  • AREA (North/South) is manual — the app never guesses it
  • Everything auto-saves as you type

IF SOMETHING GOES WRONG

  • App killed / tablet dies → just reopen it — everything saved is intact, track resumes
  • Buttons dimmed → survey is closed (read-only); start or load one from DATA
  • Missed something? Add it post-flight: REVIEW → + missed obs (9001+)
  • Export before leaving the aircraft: REVIEW → Export → save/send the ZIP
  • Paper is the fallback — switch any time, no shame
